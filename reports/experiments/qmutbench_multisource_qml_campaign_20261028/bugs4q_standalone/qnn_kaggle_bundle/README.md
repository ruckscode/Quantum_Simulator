# Bugs4Q grouped QNN training

Upload `Bugs4Q_grouped_QNN_training.ipynb` to Kaggle, enable Internet for installing the pinned PennyLane package, then select **Run All**. It embeds the verified 62-snapshot manifest and exact training source. Training uses CPU PennyLane `default.qubit` analytic backpropagation; no GPU is needed or claimed. It performs 5-fold GroupKFold by bug issue, trains four supervised QNN/hybrid variants and matched classical controls, validates a parameter gradient against centered finite differences, and incrementally saves histories, checkpoints, metrics and OOF predictions. Download `bugs4q_qnn_results.zip` from the Kaggle notebook output when complete. Kaggle account interaction is needed to upload/run; no Kaggle browser session is available here.
